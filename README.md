# Job Market Analytics System

# Project Overview

The **Job Market Analytics System** is a data analytics project that collects remote job listings from a public API, processes and cleans the data using Python, stores the structured data in MariaDB, performs SQL-based analysis, and generates an Excel report.

The project demonstrates how different technologies can work together in a real-world data analytics workflow.


# Project Objectives

The main objectives of this project are:

- Collect real-world job market data using an API.
- Understand and process JSON data.
- Clean and transform job data using Python and Pandas.
- Identify jobs requiring specific technical skills.
- Store structured job information in a relational database.
- Perform SQL-based job market analysis.
- Generate an Excel report automatically.
- Understand the complete data pipeline from API to report.
